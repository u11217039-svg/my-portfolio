幾A幾B 猜數字遊戲

同一個遊戲，從單機網頁一路做到 Google 帳號個人存檔

  • 答案由 0～9 中四個不重複的數字組成，可以 0 開頭。
  • A 表示數字與位置都正確，B 表示數字正確但位置不同；猜中 4A0B 就完成本局。
  • 四個版本都附有「除錯模式」，方便驗收時查看目前這一局的答案。

四個版本

點卡片可以開啟各版本的遊戲。版本三與版本四在新分頁開啟，資料會存到 Google 試算表。

版本 1

單機基本版

輸入四個數字，判斷幾 A 幾 B，並有猜測紀錄與除錯模式。

  • HTML
  • CSS
  • JavaScript
開啟遊戲

版本 2

多局歷史版

每局分開記錄，開新局可保留舊局，並標示進行中、已猜對、未完成。重新整理後歷史會清空。

  • 多局歷史
  • 局狀態
開啟遊戲

版本 3

代號＋雲端存檔版

輸入代號，每次有效猜測自動存到試算表；同代號可讀回並續玩未完成的局。

  • Google Apps Script
  • 試算表
開啟遊戲（新分頁）

版本 4

Google 帳號個人存檔版

用 Google 帳號辨認玩家，每個人有自己的試算表；同帳號回來就能讀回續玩。

  • Google 登入
  • 個人存檔
開啟遊戲（新分頁）

版本三：代號不是登入，知道同代號的人可以操作同一份紀錄，請不要用個資當代號。

版本四：需要登入 Google 並授權。首次使用會要求試算表與帳號 Email 權限，授權範圍比單一遊戲檔案更廣；進入後還要按「建立我的遊戲存檔」，才會在你自己的雲端硬碟建立試算表。畫面可能出現「未驗證」提示，這是課堂作品的正常現象，請只授權你信任的程式。
